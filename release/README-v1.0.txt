Yara Research 1.0.0 for Windows x64

Run Yara Research_1.0.0_x64-setup.exe, then launch Yara Research from the Start menu.
This is an unsigned local build. SHA256SUMS.txt records the installer checksum.

Add paper starts an offline research workspace. Discover papers optionally searches OpenAlex.
Select any paper to explore its citing works, references, status, tags, and Markdown notes.
Settings & backups exports and restores complete .yara workspace archives.

No Node.js, Rust, cloud account, or subscription is needed after installation.
Microsoft WebView2 is required; the installer can download it if missing.

The editable project, usage instructions, architecture, and test evidence are in the parent folder.
Clean-machine installation/uninstallation and missing-WebView2 bootstrapping remain untested.
